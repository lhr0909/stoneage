# Native client source provenance

Imported game source from https://github.com/alrightlook/StoneAgeMobileApp at
`8c870c87ce1305c52fb6713bf824619467847bba`, directory `android-project/jni/src`.
The Android dependency bundles are not imported; CMake uses installed SDL libraries.

This is a later-generation SDL port being adapted to the 2.5 server and asset
profile. It is not original 2.5 client source. Protocol/gameplay compatibility
must be validated against the local server. Original source encodings are preserved.
